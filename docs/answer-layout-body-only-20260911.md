# 聊天回答正文

`reactModelConclusionHtml` 使用 `conclusionRichTextHtml` 渲染模型回答和系统结论。正文模式隐藏额外的结论标签，保留标题、段落、列表与显式重点。包含多个装备章节的连续文本可按章节和组合分行。括号内说明、小数及千分位数字保留在原条目中。

## 阵容与装备对比图

阵容查询的聊天正文下方可显示各阵容的核心英雄及其携装。已确认的主 C 和主坦优先展示；缺少直接角色证据时，根据携装单位的职业、阵容名和装备组合出现的场次展示「主 C 参考」或「主坦参考」。只有携装信息时展示「携装核心」。图标使用同一条结果中的英雄、羁绊和装备标识；直接查询缺少图片地址时，前端按游戏实体标识补齐 MetaTFT 图片地址。

回答中的 Markdown 表格有数据行、名称列和可识别的数值列时，聊天正文自动显示横向条形图。支持行间空行、全角竖线、单行结果，以及单独放在 Markdown 围栏中的数值表。选择指标后，每行显示该指标的数值和条形。平均名次默认从小到大，前四率、吃鸡率和场次默认从大到小。箭头可反转排序，选择「原始顺序」可恢复回答给出的次序。同值保持原顺序，缺失值排在末尾。排序直接使用这条回答的数据。

阵容名称旁显示代表头像。前端优先读取该条回答的阵容成员，匹配名称中指明的英雄，或使用带有头像的核心成员。需要补全时，按该条回答的赛季加载英雄目录，再尝试匹配羁绊图标。页面按赛季和目录类型复用成功的目录请求。未匹配到具体图标时显示通用棋子标记。无法构成数值对比的表格保留常规表格排版。

装备行优先使用回答携带的装备图标，缺少匹配时通过 `GET /api/item-icons?seasonContextId=…` 获取对应赛季的名称、别名与图标。组合名用加号或顿号分隔时，按原顺序显示各件装备。无法唯一匹配的装备显示占位标记。

正文布局和识别规则由 `src/app/small-window-ui/conclusion-rich-text.js` 和 `answer-comparison.js` 实现。相关回归在 `test/conclusion-rich-text.test.js` 中。
