# Patch 18.5 release maintenance

Patch 18.5 was verified on 2026-10-22 against Riot's Traditional Chinese and English release notes. Riot published the article at `2026-10-20T18:00:00.000Z`, which is 2026-10-21 02:00 in Asia/Shanghai.

Scope:

- add one 18.5 release revision with 71 reviewed before/after numeric records;
- retain the complete 18.1–18.4 timeline and expose 463 numeric records across the public announcement history;
- make the same 18.5 records available through official patch evidence, `patch_facts`, entity association, and semantic patch documents;
- update the Set 18 announcement version, subtitle, and notice;
- regenerate the mini-program patch-note payload from the canonical history.

Non-numeric official changes are summarized but not represented as numeric endpoints: AD/AP Augment tailoring, Mama Beak's shorter Mana lock, Heart of Steel being re-disabled, Item Extraction no longer granting Veigar, new Pandora's Items II+ / II++, Wisp filtering and stage availability, bug and stability fixes, and 52 restored cosmetics. As of the verification date, Riot's 18.5 article has no B-patch section.

No new Tool, runtime, permission, Skill, database migration, or dependency is introduced. Quick Task and ReAct routing remain unchanged.
