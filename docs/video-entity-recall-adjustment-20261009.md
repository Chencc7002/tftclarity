# 视频实体检索：减少严格过滤导致的空结果

2026-10-09：已完成本地实现与测试，未部署或修改生产配置。生产的当前版本与开关本轮未重新查询。历史发布基线见 `video-entity-production-20260910.md`。

## 规则调整

新增服务端配置 `BILIBILI_ENTITY_RECALL_MODE=off|shadow|enforce`，默认 shadow。旧的 `BILIBILI_ENTITY_MATCH_MODE` 保持原职责。只有两个开关均为 enforce，才启用核心实体筛选、辅助实体排序及补搜。

- off：原来的严格实体过滤，无新增搜索请求。
- shadow：返回结果、排序、视频 Evidence 和调用序列与旧策略一致，只在 entityFilter.balancedShadow 记录同批候选的核心匹配情况；不会为了影子观察增加上游请求。
- enforce：使用以下新策略，保留原策略作为可回退路径。

对于无明确并列要求的混合类型描述，以最先提到的实体类型为核心；“羁绊 + 英雄”组合以英雄为核心。核心类型中的多个实体全部保留为条件，不随意丢弃第二个英雄。其他实体作为偏好，标题命中优先排序，版本优先级仍保留。

| 查询 | 必须命中标题 | 排序偏好 |
| --- | --- | --- |
| 剑圣带羊刀 | 剑圣 / 易的可信别名 | 羊刀 |
| 剑圣带羊刀无尽 | 剑圣 / 易的可信别名 | 羊刀、无尽 |
| 斗士剑圣阵容 | 剑圣 / 易的可信别名 | 斗士 |
| 羊刀给剑圣怎么样 | 羊刀的可信别名 | 剑圣 |
| 剑圣和羊刀、标题同时包含剑圣羊刀 | 两个实体均需命中 | 不放宽 |
| 剑圣或霞 | 任一实体命中 | 保留 OR |
| 已收录命名阵容 | 阵容名称或别名 | 不降为任意成员 |

单实体、普通/光明装备身份、单字词边界均保留。歧义、混合 AND/OR、排除表达及目录不可用暂时仍不放宽；未收录外号仍是 unscoped。这是有边界的确定性规则，不代表通用自然语言语义识别。

辅助词未全部在标题出现时，Evidence 标记 `allEntitiesMatched=false`，并输出 `video_entity_secondary_terms_unconfirmed` 警告，不能将这类结果宣称为完整匹配全部条件。

## 结果不足时补搜

输出条数和上游召回条数分开，要求 1 条结果不会只向上游取 1 条候选。首轮仍使用原查询；结果不足后使用核心实体的可信别名简化查询，避免重复相同的关键词/页码。如果原查询已是简短实体名，可尝试另一个已收录别名；仍不足时继续该查询下一页。

整次工具执行最多追加 2 次搜索，双生态共享上限；追加搜索共享 4 秒网络时间窗口，并继承调用者取消信号，不延长 Agent 原有 deadline。每个生态原有详情上限不变。已查询详情和视频候选按 ID 复用、去重；补搜失败保留合格的已有结果。实体歧义、目录失败和普通无实体查询不补搜。

所有候选继续经过游戏领域、核心标题、详情更新后的标题和版本规则。过滤后仍不足时返回真实不足，绝不以无关视频凑数。

逐条视频 Evidence 记录真正命中的搜索词和页码；entityFilter 记录 requiredEntityIds、preferredEntityIds、recallAttempts、additionalSearches 和停止原因。事实仍由原注册工具的 B 站适配器检索，无新增 Runtime、Skill、工具或客户端权限。
