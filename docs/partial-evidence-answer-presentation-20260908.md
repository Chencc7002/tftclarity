# 部分证据回答展示修复（2026-09-08）

用户反馈：回答不能只显示“已取得部分有效证据”，应先展示实际取得的结论，再说明缺少什么及其对结论完整度的影响。

## 根因与范围

当前 ReAct 的无进展兜底只对部分出装类型提供确定性摘要。阵容、资料与名称解析等已通过 Ledger 校验的 Evidence 会落入通用状态文案。前端还将所有系统兜底统一标为“模型输出未通过校验”，无法区分查询中断与实际的模型校验拒绝。

新增 `src/react/partial-evidence-answer.js`，仅消费已有 Evidence：展示阵容成员及实际统计、出装候选的具体装备、资料事实或已确认对象，并列出缺失统计、站位、成员出装、资料字段与查询失败所造成的限制。无足够事实时明确说明不能形成具体结论。不会把空值变为零，不生成可信度百分比，不把名称识别当成表现依据；历史 Evidence 不进入当前信息摘要。

ReAct 无进展、重复调用、超时恢复及相关模型失败兜底复用该展示逻辑。保留既有约束出装、装备竞争、单英雄排行等专用摘要；混合 Evidence 的已知信息和引用均保留。超时继续使用已有的截止时间 Evidence 筛选与迟到结果隔离。

前端结论卡片按“已确认的信息 → 还缺什么 / 结论边界”显示。提示文案区分部分完成、查询超时和实际校验拒绝；未通过校验的原文默认折叠，位于可用结论之后。

这不是 Skills 控制或新 Runtime：未修改工具权限、参数校验、预算、Evidence 验证、`nextActionAffordance` 或 Quick Task 路由；未增加检索或模型调用。既有文档中的安全边界继续适用，以当前代码的工具结果字段为展示依据。工作区原有无关修改均保留。
