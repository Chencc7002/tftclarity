# 18.2 Agent 公告证据接入

2026-09-10。基线为已上线 `bf208ae`，使用同一独立发布树，未带入主工作区无关修改。

根因：页面数值历史含 18.2，但 `official-patch-evidence.js` 未登记该版本，现有 `patch_facts` 工具因此返回 `not_found`，语义知识文档生成也遗漏 18.2。

修复：登记 18.2，并从已核实的 157 项共享数值生成官方证据。补齐英雄、羁绊及装备的实体标识和数值字段；实体映射依据现有 Set 18 目录，保留物理/法系形态区别。灵火和强化符文没有已核实 ID 的条目保留空标识，仍可按官方名称及数值检索。语义文档避免重复加入同一数值修订。工具、参数权限、运行路径、提示词和 Evidence 校验均保持现有契约。

来源：https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/teamfight-tactics-patch-18-2/ 。阿狸技能法强倍率 425/640% → 455/685%，每格伤害衰减 20% → 21%。知识库范围为已维护的数值公告，未声称覆盖完整外观和问题修复清单。

新增回归验证当前页面版本必须有同值官方证据，覆盖实体关联、两项阿狸变化、历史版本隔离、默认服务器版本、来源链接、语义检索及 ReAct 工具执行和 Evidence 入账。主回归 1563 通过、7 跳过；集成 235 通过、1 跳过；离线评测 50/50。

`node scripts/smoke-patch-18-2-agent.mjs --live` 用已配置真实模型和检索器验证明确 18.2、当前版本和历史 18.1 三类提问；运行结果另存部署记录，不以注入 Provider 测试替代真实验收。


候选验收发现语义工具的既有 800 字符上限会截掉大版本后部条目。因此在原索引中追加按实体及修订分组的短文档，每段不超过该上限，沿用相同来源、版本和事实类型，不扩大工具预算。新增测试通过真实语义工具的有界返回检查阿狸两条事实，并保证 157 个数值变更各有且只有一个分段覆盖。第一次候选尚未激活，旧服务一直保持在线。

主工作区缺少已上线的 `official-patch-facts.js` 等较新链路；本次部署以生产分支为准，只向主工作区同步公告数据与证据登记，避免用旧工作区覆盖线上工具架构。
