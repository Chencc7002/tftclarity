# 体验引导系统 v1

本次实现的是网页体验引导：语音输入提示、常用工具收藏提醒，以及回答末尾的下一步入口观测。
已接入本地网页；没有部署或修改生产配置。它不是英雄策略推荐器，也不进入 Agent、Skill、
TaskFrame、ExecutionPlan 或 ReAct 的执行路径。

## 职责

- `src/app/small-window-ui/experience-guidance.js`：确定性调度，主动提示互斥、优先级、
  冷却、接受/稍后/不再提醒、完成状态，以及本地有界计数。
- `src/app/small-window-ui/experience-guidance-ui.js`：原生输入事件、输入法状态、
  2 秒停顿、输入框提示、设置开关、页面状态与回答入口曝光观测。
- `quick-tool-preferences.js` / `quick-tool-library.js`：继续拥有工具使用门槛、收藏状态
  和原有偏好；仅在实际获准展示时领取提醒，避免被公共调度抑制时浪费每日机会。
- `voice-input.js`：继续拥有麦克风和语音识别；识别真正开始后记录已学会使用语音。
- `app.js`：组合模块；回答下一步仍使用服务端返回的原始动作与查询参数。

公共模块只接收提示候选与显示/隐藏回调，不检索数据、不调用模型、不生成下一步业务动作。
业务动作由用户点击后在原模块执行。已存在的收藏、冷却、永久拒绝记录继续生效。

## 产品规则

| 项目 | v1 行为 |
| --- | --- |
| 语音门槛 | 当前手动输入超过 20 个 Unicode 字符：20 不触发，21 开始具备资格 |
| 出现时机 | 停顿 2 秒，输入法未在组字，语音可用且未录音，焦点仍在输入区域 |
| 非手动输入 | 粘贴、拖入、自动填充、程序填入和语音转写不计入手动字数 |
| 语音执行 | 点击“试试语音”才启动；原文保留，识别内容可继续编辑，不自动发送 |
| 收藏门槛 | 保留近 7 天至少 3 次且跨至少 2 天；收藏提醒总体每日最多一次 |
| 提示协调 | 同一页面最多一个主动提示；同时满足时语音优先于收藏 |
| 频率 | 主动提示共享至少 30 分钟间隔；同一提示显示后冷却 24 小时 |
| 稍后 | 该提示冷却 7 天 |
| 不再提醒 | 永久关闭该提示；收藏按工具分别记录 |
| 已使用 | 成功开始过语音后不再教学提醒；已收藏的工具由收藏模块排除 |
| 暂停情境 | 页面隐藏、查询中、首次引导、模态框、移动端设置覆盖、输入框不可见 |
| 全局开关 | 设置中的“体验提示”；关闭主动提示，保留回答末尾下一步按钮 |
| 下一步建议 | 回答下方常驻，曝光/点击接入统一计数，不占用主动提示冷却 |

字数以去掉首尾空白后的 Unicode code point 计数，不以 UTF-16 长度计数。
从长文本粘贴或程序填入后，继续键入的字符单独累计，不能只加一个字就误触发提示。
候选等待最多 2 分钟；过期候选在下一次调度时丢弃，不跨会话排队。

原有 `toolLater` / `toolNever` 文案用于收藏；语音有独立的“稍后 / 不再提醒”中英文文案。
提示保持输入焦点，支持 Tab 经过麦克风进入提示按钮，并可在手机宽度下换行。

## 状态、观测与回退

使用当前浏览器 `tftagent.experienceGuidance.v1`，只保存开关、冷却时间、固定类别计数、
已完成/拒绝状态与经过约束的工具 ID。不保存用户问题、回答、语音文本、服务端动作参数，
也没有新增远程上报。存储不可用时退化为会话内状态；跨标签页通过 storage 事件同步偏好。
这里没有跨设备同步，也没有多标签页同时写入时的原子锁。

曝光在提示实际展示后记录；下一步入口通过 IntersectionObserver 记录，每个回答在当前
页面生命周期内去重。点击只记 accepted，不假称下游查询完成；语音完成以识别开始为准，
收藏完成以本地收藏成功为准。计数保留在本地供后续诊断，不将其当成线上效果证明。

调度器支持 `mode: "shadow"`：评估候选并产生有界回调，不展示、不修改偏好、不领取旧收藏
提醒、不执行动作。影子验证后本地网页使用 active 模式。旧收藏提醒分支保留：创建工具库时
不传入 guidance 即走原有路径；用户开关可立即关闭新系统的主动提示。未修改线上开关。

## 验证

- 自动测试：20/21 字、Unicode、IME 替换、粘贴/转写/程序预填、优先级互斥、频率与到期、
  拒绝持久化、全局关闭、跨标签页关闭、存储故障、下一步去重与数据最小化、影子零副作用、
  旧收藏规则及展示后领取。
- 浏览器：本地 fixture 页面确认 20 字不展示、21 字停顿展示；1280 与 390 像素宽度检查；
  键盘能到达提示按钮；“不再提醒”刷新后仍生效。未申请真实麦克风权限。
- 完整回归结果记录于 `.cache/experience-guidance-main.log`、
  `.cache/experience-guidance-integration.log`、`.cache/experience-guidance-eval.log`。
  最终主回归 1,357 通过 / 7 跳过 / 0 失败；集成回归 235 通过 / 1 跳过 / 0 失败；
  Agent 离线评估 50/50。最终浏览器页面没有控制台脚本错误，设置总开关可操作。

仓库已有大量无关未提交变更，本次没有回退或整理它们；也没有把独立发布工作区中的
Agent/Skill 灰度进度当成此体验系统的发布状态。
