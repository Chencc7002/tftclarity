# 聊天装备查询的低样本补充

英雄单件装备排名、指定装备表现、装备对比和完整出装查询按原门槛生成主要结果。指定目标未达到门槛、主要结果为空，或达到门槛的条数少于用户请求的榜单长度时，聊天服务可用同次查询已过滤的数据补充低样本结果。按场次从高到低取缺少的条数，最后一条的场次为本次补充门槛。零样本和已识别的特殊装备离群数据不参与补充。

低样本补充不修改会话偏好、版本、时间范围、星级或原榜单的稳定性判定。回答标明原门槛、补充门槛和各项实际场次。用户指定的硬性门槛保留，明确允许降低时可以补充。没有正样本时沿用原查询结果。

`TFT_AGENT_EQUIPMENT_SAMPLE_MODE` 支持 `off`、`shadow`、`on`。影子模式仅记录命中的查询类型、两个门槛和补充条数。启用时，同一注册工具在结果中携带 `sampleReference`，聊天回答根据本轮引用的装备证据展示补充数据。
