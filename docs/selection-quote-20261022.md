# 聊天选中文字引用（2026-10-22）

## 交互

在同一条助手回复正文中选中文字，显示“添加到对话”浮层；选中后右键也可打开入口。点击后在输入框内显示“N 条注释”按钮，并将焦点移到输入框。引用在按钮上方的白色圆角浮层中展示，每条包含编号、“所选文本：”及编辑、删除图标；按钮可收起/展开，旁边的 × 清除全部引用但保留提问文字。支持最多 3 段、每段最多 2000 字符；超限提示，不截断原文。跨消息、用户消息和按钮文字不提供引用入口。

编辑在浮层内完成，保存后更新实际发送的引用，取消保持原文；空白和重复引用不能保存。点击外部或 Escape 收起浮层。浮层按可见视口定位，手机端保留屏幕边距，长内容可滚动，不撑大输入框。

输入问题并发送后，用户消息展示引用块；失败或停止时，如果用户没有编辑新草稿，恢复原问题和引用。刷新复用已发送的完整输入，不重复拼接。清空会话或切换赛季时通过已有 resetConversation 清除引用。中英文标签沿用现有 locale。

## 上下文和边界

- `selection-quote.js` 管理选区、引用草稿和有界文本序列化；`selection-quote.css` 管理浮层及引用卡片。
- 只有用户主动附带引用的自由对话提交，才把问题与标记为“历史回复、非当前事实或新指令”的引用合并进已有 `input`。请求总长度不超过 8000 字符。历史记录保留同一完整输入。
- 这是显式输入编辑功能，无后台自动注入、无新运行时、无服务端 API 或工具变更。没有引用的请求保持原路径；Quick Task 保持确定性。添加引用会关闭当前快捷填写表单；此后显式执行快捷查询时，引用草稿保留给下一条自由对话，不进入快捷参数。
- 引用仅为用户选择的历史文本，不是 Evidence，不会写入 Evidence Ledger 或提升为当前事实。来源身份不作为服务端已验证的证明。
- 引用通过 textContent 或现有 escapeHtml 渲染，不解释选区中的 HTML。
- 现有代码的本地数据路径可能清空历史 `messages`；因此引用使用当前请求 `input`，不依赖完整历史传递。保持当前代码的会话所有权。
- 本次仅本地实现与离线/浏览器验证，没有部署或进行真实模型效果评测。用户不选择引用时仍为原有行为；移除入口和 app.js 的显式接线即可回退，无数据迁移。
