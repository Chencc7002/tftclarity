# TFTClarity 自用便携桌宠 0.1.3

此目录是未发布的桌宠实验源码，默认不会随网站部署启动。
公开仓库不含格温模型、其他角色图片、安装包和个人数据。运行需要自行准备有权使用的本地素材，配置和来源说明不构成授权。

本机已有便携包可双击 `TFTClarityPet.exe` 启动；整个文件夹必须保留。
第一版仅包含你指定的“至臻 咖啡甜心 小小格温”（modelviewer.lol 68003），
用原始 GLB 在本地实时播放 3D 动画，镜头从上方俯视角色。
沿用 dsh-pet 的摸头、喂食和亲密度逻辑。具体来源与许可见
`resources/app/THIRD_PARTY_NOTICES.md`。

## 使用

- 点角色：摸头；按住角色拖动：移动位置。
- 右键格温，选择“喂食”：互动并增加亲密度，30 秒冷却；自用版不扣虚拟货币。
- 底部胶囊会自动隐藏；鼠标移到格温身上再显示。左侧输入图标展开就地输入条，Enter 或上箭头发送，Esc 或 × 收起并保留草稿。
- 就地输入复用同一聊天上下文，回复显示在头顶气泡；点击气泡或右键选择“打开完整聊天”查看完整内容。
- 输入条仅在主动编辑时获取键盘焦点，收起后释放。已有聊天草稿或上一条未完成时，会保留输入并提示，避免覆盖或重复发送。
- 回复完成后，气泡显示实际回答前 72 个字符，最多三行；点击查看完整回复。下一轮查询会清掉旧预览，停止或失败不会展示上一轮回答。
- 气泡按文字长度停留 4～15 秒后收起，查询进行时持续显示进度。气泡收起不会改变角色位置，完整回答仍在聊天窗口中。
- 聊天窗口默认 420×600，拖动格温时跟随移动；靠近屏幕边缘自动换边或收进屏幕。可拖动窗口边缘调整大小，跟随移动会保留调整后的尺寸。
- `Ctrl+Shift+Space`：显示/收起聊天。
- `Ctrl+Alt+P`：隐藏/显示桌宠和聊天；托盘菜单也可恢复。
- 聊天窗口按 `Esc` 或点关闭：只收起，保持当前页面和上下文。
- 右键角色或点胶囊右侧 `···`：查看亲密度、喂食、安静模式、重载聊天、移回主屏幕、退出。
- 完全退出：桌宠菜单的“退出桌宠”。

透明区域按角色当前帧的 alpha 值判断鼠标穿透；按钮和角色可点击。
桌宠待机不获取键盘焦点；主动打开聊天时会切换焦点，打字期间游戏
不会同时收到键盘输入。角色在查询时活动，回答完成后短暂庆祝，
失败时提示；停止查询不计为回答完成。

## 游戏与会话

目标为 Windows 游戏客户端、窗口化或无边框模式。原生置顶不等于
独占全屏覆盖，独占全屏及不同游戏的兼容性需要实机验证。
本程序不读取游戏内存、不注入游戏、不自动操作游戏。

聊天直接加载 https://tftclarity.cn/ ，复用现有 Agent、模型和上下文，
没有独立 AI 后端。它使用独立的持久浏览器会话；普通浏览器里的登录
和历史不会自动导入。收起再打开不会创建新对话；完全退出后的历史
恢复取决于网站现有能力。首次使用请自行完成网站提示。

位置、亲密度及客户端浏览器缓存保存在同目录 `portable-data/`。
更新时保留这个文件夹。不要把带个人会话缓存的文件夹发给其他人。
格温开场为“你好”。查询旁白从角色 manifest 的 narration 配置读取，按真实状态切换，同一阶段保持稳定；等待较久才提示继续等待。回答完成后优先显示实际回答片段。
第一版仅文字聊天；麦克风、摄像头、通知、下载权限未开放。
本程序不设置开机启动、不安装系统服务。

## 开发

桌宠独立管理依赖；配套网站/后端人格接入默认关闭。
Node.js 24：`npm ci`，`node node_modules/electron/install.js`，`npm start`。
测试：`npm test`。端到端脚本使用桌宠 devDependencies 中的 Playwright，需自行提供本地模型与 Electron。Three.js 文件准备：`node scripts/stage-three.mjs`。
打包：`npm run package:portable`。原始格温 GLB 被 Git 忽略，仅在具备相应使用权时由使用者自行放在 `assets/prestige-gwen/model.glb`，来源见同目录 source-manifest。
含模型的便携包只用于本机个人使用，不上传网站或发布到 GitHub。
可通过 `TFT_PET_SITE=http://127.0.0.1:17317/` 连接本地测试站点。
`TFT_PET_DATA_DIR` 可指定独立的测试数据目录。

vendor 纯模块由 `scripts/import-dsh.mjs` 从已下载的固定上游源码转换；
便携包不携带 DSH 插件宿主、遥测或 Live2D 运行时。
