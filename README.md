# tftclarity

> 面向《云顶之弈》的 AI 数据决策助手：将玩家自然语言问题转换为结构化查询，结合统计数据、证据约束和领域知识，生成可解释的装备与阵容分析。

## 项目简介

tftclarity 是一个用于探索 **TFT 数据分析 + Agent 推理 + 机制知识建模** 的实验型项目。

不同于传统数据站点只展示胜率、平均排名和榜单，tftclarity 的目标是解决玩家更关心的问题：

- "霞已经有羊刀，剩下两件怎么补？"
- "为什么这个装备组合更适合这个英雄？"
- "这个阵容当前版本还能玩吗？"
- "这个高胜率是否只是低样本导致？"

系统尝试从「数据查询」进一步走向「数据解释」，不仅回答结果，也解释结果背后的统计依据、机制因素和适用条件。

# 当前版本状态

## Beta 测试版本（当前）

当前版本主要用于验证完整产品链路：

```
自然语言输入
        ↓
Query Understanding
        ↓
TaskFrame
        ↓
Capability Matching
        ↓
Execution Plan
        ↓
MetaTFT 数据获取
        ↓
SQLite 数据缓存与统计验证
        ↓
Evidence Bundle
        ↓
AI 辅助结论生成
```

当前重点验证：

- Agent 是否能够正确理解 TFT 查询需求
- 查询计划是否稳定
- 数据结果是否可验证
- AI 总结是否受到证据约束
- 复杂装备比较是否能够生成合理解释

当前版本并非最终生产架构，SQLite 主要用于快速验证数据流、缓存策略和 Agent 工作流程。

# 已实现能力

## 自然语言查询

支持玩家使用中文俗称和自然表达：

- 羊刀、无尽、巨杀、石像鬼
- 英雄简称和常见别名
- 阵容名称
- 已拥有装备条件
- 样本量、排序目标等限制条件

系统会解析：

- 英雄
- 装备
- 星级
- 阵容
- 查询目标
- 统计约束

无法确定实体时不会直接猜测，而会进入澄清流程。

---

## 数据分析能力

当前支持：

- 英雄三件套推荐
- 已有装备补全
- 单装备替换比较
- 多装备组合分析
- 阵容排行
- 阵容趋势分析
- 装备与英雄匹配分析

输出不仅包含：

- 平均排名
- 前四率
- 胜率
- 样本量

也会考虑：

- 样本可靠性
- 低样本风险
- 选择率导致的竞争压力
- 不同条件下的适用范围

# Agent 架构

当前项目已经从简单查询脚本演进为多阶段 Agent 架构：

```
User Question
      ↓
TaskFrame
      ↓
Capability Matcher
      ↓
Execution Plan
      ↓
Tool Executor
      ↓
Evidence Validation
      ↓
Hybrid Answer Service
      ↓
Final Response
```

设计原则：

- LLM 不直接决定数据结果
- LLM 不修改统计事实
- 所有重要结论必须关联 Evidence
- 数据查询和自然语言解释分离
- 失败时自动降级到确定性结果

# 当前数据架构（测试版）

当前使用 SQLite 作为验证数据库：

用途包括：

- MetaTFT 数据缓存
- current stats 快照
- 语义索引实验
- 查询记录
- 测试数据持久化

选择 SQLite 的原因：

- 部署简单
- 适合单机开发验证
- 方便进行 Agent 流程测试
- 降低早期基础设施成本

# 未来核心方向：TFT 机制知识系统

当前数据网站只能回答：

> 哪个装备统计表现最好？

未来 tftclarity 希望回答：

> 为什么这个装备更适合？在什么条件下会变化？

计划建设：

## Mechanism Knowledge Layer

将 TFT 理解拆分为可维护知识：

- 输出类型
  - 持续输出
  - 爆发输出
  - 技能循环

- 装备乘区
  - 面板
  - 暴击
  - 攻速
  - 增伤
  - 破甲
  - 生存

- 资源关系
  - 大剑竞争
  - 弓需求
  - 装备溢出

- 条件因素
  - 固定已有装备
  - 阵容环境
  - 版本变化
  - 强化符文

最终形成：

```
统计结果
    ↓
机制因子识别
    ↓
条件分析
    ↓
可解释结论
```

# 设计目标

tftclarity 不希望成为另一个装备排行榜，而希望成为：

> 一个能够理解 TFT 游戏机制，并结合实时数据帮助玩家做决策的 AI 分析助手。
