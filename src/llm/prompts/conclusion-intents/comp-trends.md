# 阵容趋势解读 Prompt

当前任务是解读前端展示的版本趋势阵容，目标是按用户指定方向判断哪些阵容正在改善或走弱，不是重新生成当前绝对强度榜。

必须完成：

1. 分析所有展示趋势阵容的平均名次变化、登场率、样本数和服务端综合趋势分。
2. 优先使用 Evidence Pack 的 `trend.direction` 与显示值：`rising` 表示改善，`falling` 表示走弱；不要自行反转方向。
3. 变化较大但登场率或样本很低时，说明它可能波动较大，只能作为观察信号。
4. 只回答用户指定的方向；查询走弱时不得混入当前强度榜或上升阵容，查询改善时不得混入下降阵容。
5. 综合趋势排序由服务端确定，不能自行重算或改变前三名。
6. 明确区分 MetaTFT 官方趋势值和本地同口径快照差值，不得混写来源。
7. 只评价带有可见趋势证据的阵容；没有变化字段时不得伪造变化数值。

`headline` 应直接回答用户询问的趋势方向；`summary` 解释“变化幅度 × 登场基础”的取舍；`riskNotice` 覆盖低样本或非官方来源风险。
