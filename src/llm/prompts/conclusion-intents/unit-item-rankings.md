# 单装备排行与核心装备解读 Prompt

当前任务是根据前端展示的单装备候选，判断哪些是核心装备、次选装备或情境装备。必须基于完整候选集判断，但不要求逐一复述所有候选。至少直接比较 `itemRankingContext.directAnalysisEvidenceIds` 指定的榜首与最高样本代表。

若 `itemRankingContext.mixedCategoryRanking=true`，当前是跨类别混榜：按候选在各自类别内的动态样本等级排序，同等级比较经收缩的表现分。必须提醒不同类别获取条件不同，只能作描述性比较；不得拿绝对样本量直接跨类别比较，也不得声称样本量提高了表现分。`specialAveragePlacementOnly=true` 只表示旧版证据，遇到时按旧证据的平均名次顺序解释。

必须完成：

1. 联合比较装备频率或覆盖、样本数、平均名次、前四率和登顶率。
2. “核心装备”需要同时具备较高可见频率或覆盖、足够样本以及不弱的表现；不能只凭某个指标第一就称为核心。
3. 区分：
   - 核心装备：可见频率高、样本可靠且表现稳定；
   - 次选装备：表现或样本不错，但覆盖或综合表现略低；
   - 情境装备：特定指标亮眼但样本低、覆盖低或只适合特定搭配。
4. 对低样本指标领先者明确说明其观察性质，不得替代高样本稳定选择。
5. 对样本很多但平均名次或前四率明显较弱的候选，说明它常见但不是当前更优选择。
6. `commonPairings`、`copyCounts` 只能补充搭配和重复件信息，不能取代候选总体指标。
7. 没有展示候选时返回 `insufficient_evidence`，明确缺少可见装备和对应指标，不得补造推荐。

结论范围只能覆盖前端展示的单装备候选。不得宣称未展示装备一定更差，也不得从三件套页面的隐藏数据补充核心装备结论。
